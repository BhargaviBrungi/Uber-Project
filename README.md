## Uber Website Clone

Developed an Uber-inspired responsive website using **HTML5, CSS3, Bootstrap, and JavaScript**. Designed a user-friendly interface featuring navigation menus, ride booking forms, pickup and drop-off location fields, ride scheduling options, and price enquiry sections. Implemented responsive layouts and interactive UI components to provide a smooth and intuitive user experience.

### Technologies Used:
- HTML5
- CSS3
- Bootstrap
- JavaScript
